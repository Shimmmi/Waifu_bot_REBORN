# ТЗ: Delve Progress Quest (слой 2.3-PQ)

Статус: к реализации.  
Слой силы наёмниц поверх текущего Погружения. Кран игрока и театр колонны остаются.

Связанные документы: [VARIANT_2_2_POGRUZHENIE.md](VARIANT_2_2_POGRUZHENIE.md), [DELVE_ROLEPLAY.md](DELVE_ROLEPLAY.md), [ITEM_SYSTEM_TABLE.md](ITEM_SYSTEM_TABLE.md).

## 0. Границы

Текущий Delve — два слоя:

- кран O(1): золото → `Player.gold`, XP → основная вайфу;
- театр: пила `sawtooth()`, узлы `spine_type()`, лавка — кадр журнала.

`gold_earned` / `xp_earned` на карточке — счётчики доли крана, не кошельки.

Слой **2.3-PQ** живёт на тех же 1–3 `CompanionCard`. Не `HiredWaifu`. Не `inventory_items` основной вайфу. Летопись / flesh / psyche / тинт ветки не меняются.

Снятые законы 2.2: L4 (нет HP на HUD), L7 (сила не влияет на глубину), L10 (лавка = 0 силы).  
Кран игрока (L6, L8, L12) не трогать.

## 1. Законы

| # | Закон |
|---|--------|
| **P1** | Два кошелька. Кран игрока/ОВ без изменений. Наёмницы имеют `gold_wallet` и `xp_unspent`. Это золото не списывается с `Player.gold`. |
| **P2** | Авто. Уровень, покупка, заточка без потолка, зелья — без клика. |
| **P3** | Покупка всегда сильнее. Витрина не предлагает `ilvl <= current`. После экипа/заточки `power` строго растёт. |
| **P4** | Плоская сила. Аффиксы колонны — только имя (префикс/суффикс ОВ). Сила = `level + base_ilvl + enchant`. Нет STR/AGI, брони, legendary, пыли. |
| **P5** | `d_fair = f(party_power)` — комфорт, не стена. Глубже комфорта сток HP растёт как `0.10 * 2^(d/d_fair - 1)`. Кадр PQ = `last_d`, не пила. |
| **P6** | Пока есть HP — идут вниз. HP = 0 у всех → wipe. Экип, расходники, уровни, кошельки, сила, золото/XP сохраняются. Спавн на последнем достигнутом городе (`checkpoint_d`), иначе с поверхности. |
| **P7** | Детерминизм: один сид + те же входы → те же покупки, сток и wipe. Без LLM. |
| **P8** | Предмет колонны нельзя надеть на ОВ. Отдельные таблицы. |

Канон прогрессии — `CompanionCard`. `DelveCompanion` — зеркало на ствол.

## 2. Формулы

```
xp_to_next(L) = 40 + 20*(L-1) + 3*(L-1)^2
power_level   = level
ilvl(item)    = base_ilvl + enchant_level          # enchant без потолка
power_gear    = sum(ilvl экипированных слотов)     # двуручник считается один раз
power         = power_level + power_gear
hp_max        = 40 + 8 * power
party_power   = sum(power живых в отряде)
d_fair        = floor(8 + 0.40 * party_power + 0.0038 * party_power^2)  # комфорт, не стена
band(d)       = max(1, ceil(d / 20))   # кран золота/XP — только от pb_depth, не от d_max
gear_price    = round(12 * base_ilvl * 1.12^(min(band, item_tier)-1))  # T1 всегда 48, банда не взрывает цену
sharpen_cost  = round(4 * base_ilvl * N)           # N = следующий +; цена от базы, не от текущего ilvl
```

Старт: level 1, без экипа, power 1, hp 48, `d_fair` ≈ 8. Комфорт от сырой силы, без `power_eff` и без текущей глубины.

Авто-левелап: пока `xp_unspent >= xp_to_next(level)` — списать XP, `level += 1`, пересчитать `power` и `hp_max`. Текущее HP от левелапа не восстанавливается.

ID двуручника: слот 1 несёт ilvl, слот 2 пуст и заблокирован.

## 3. Каталог экипировки

Слоты как у ОВ: 1 оружие, 2 оружие/щит, 3 костюм, 4–5 кольца, 6 амулет.

`slot_type`: `weapon_1h`, `weapon_2h`, `offhand`, `costume`, `ring`, `amulet`.

Именные базы — `data/delve_gear.v1.json` (80 строк: 8 семейств × 10 тиров).  
`base_ilvl = tier * 4` (T1=4 … T10=40).

Семейства: `sword`, `dagger`, `axe`, `bow`, `shield`, `costume`, `ring`, `amulet`.

Хвост (`tier > 10`):

```
scaled_plus = tier - 10
base_ilvl   = 40 + 4 * scaled_plus
name        = "{семейство} бездны T{tier}"
```

Заточка без потолка, авто. Цена `4 * base_ilvl * N` (T1 +1 = 16, +10 = 160, +100 = 1600). Смена предмета удаляет старый инстанс (без пыли). Новый всегда `enchant_level=0` и больший `base_ilvl`; ряд плюсов не переносится.

Аффиксы — художество, не сила. При покупке сид `(pq_seed, cycle, d, card_id, slot)`: всегда префикс, суффикс ~70%. Тир аффикса `clamp(1..10, band + {-1,0,+1})`. Имена из `affix_display_names.py` (префиксы по статам, суффиксы `s_dmg_*` / `s_monster_*`, без медиа/стикеров). Заточка меняет только `+N`. Поля на `delve_companion_gear`: `prefix_stat`, `prefix_tier`, `suffix_family`, `suffix_tier`. Не писать в `inventory_affixes` ОВ.

## 4. Лавка и расходники

Узел `SHOP` (`d % 12 == 4`) — авто-резолв.

Порядок наёмницы:

1. Левелап.
2. Купить оффер с максимальным `ilvl` среди доступных по золоту.
3. Если вещь не куплена — заточить слот, если это увеличит силу.
4. Остаток — расходники до капа стака.

Витрина на глубине `d`, `band = max(ceil(d/20), ceil(pb_depth/20))` — рынок следует за рекордом, не сбрасывается в T1 на каждом спуске:

- 3 оффера экипа, сид `(pq_seed, cycle, d, card_id)`, `tier = band + {-1,0,+1}`;
- 1 заточка самого дешёвого следующего плюса, без капа `enchant`;
- 2 расходника.

Оффер с `ilvl <= current` не генерируется. Если все слоты выше банды — `scaled_plus` или заточка.

| id | Имя | Эффект | Цена | Кап |
|----|-----|--------|------|-----|
| `potion_hp` | Зелье лечения | `+0.35 * hp_max` одной | `6 * band` | 3 |
| `salve_party` | Мазь отряда | `+0.15 * hp_max` каждой | `14 * band` | 1 |

Авто-юз: зелье при `hp% < 40` (цель — наименьший %). Мазь — если двое ниже 40% или перед боссом при среднем HP < 55%.

## 5. HP, сток, wipe, города

```
d_fair       = d_max_of(party_power)
g            = max(0, depth / d_fair - 1)
frac         = 0.10 * 2^g
drain COMBAT = clip(round(hp_ref * frac), floor=3, cap=0.85 * hp_ref)
drain BOSS   = clip(round(hp_ref * 1.6 * frac), floor=6, cap=0.90 * hp_ref)
drain SHOP/REST/SURFACE/LANDMARK/TRAVERSE/BRANCH/CITY = 0
REST regen   = 0.22 * hp_max, кап 0.28     # костёр не полный хил
CITY         = HP 100% + авто-лавка + 1 травма
```

При `d_fair = 9`: глубина 9 → 10%, 18 → 20%, 27 → 40%, 36 → 80%. Сток делится по живым пропорционально `power_eff`.

`CITY_DEPTHS = 15, 40, 80, 150, 250, 400, 650, 1000, 1500, 2500`. Город важнее босса/лавки/костра на той же глубине.

| d | Имя |
|--:|-----|
| 15 | Нижний двор |
| 40 | Угольный рынок |
| 80 | Пепельный торг |
| 150 | Соляные ворота |
| 250 | Бумажный посад |
| 400 | Медный двор |
| 650 | Восковой причал |
| 1000 | Карамельный торг |
| 1500 | Коралловый град |
| 2500 | Эмалевый стол |

Wipe: все живые `hp_current <= 0`.

При wipe: `run_origin = now`, HP = max, экип/сумка/уровень/кошельки **без изменений**, `wipe_count += 1`, `last_d = checkpoint_d` (0 если город ещё не пройден). Если есть город — сразу `visit_city` (лавка + 1 травма). Кран игрока (`t_origin`) не сбрасывается. Спуск продолжается со следующего узла после города.

## 6. Кран наёмниц и баланс

Отдельный кран, те же `walk_capped_grant`, свои капы. Делёж по loyalty.

```
merc_gold_cap_day(band) = 80 * band     # band = ceil(pb_depth / 20), минимум 1
merc_xp_cap_day(band)   = 60 * band
```

Банда крана считается только от рекорда (`pb_depth`), не от теоретического `d_max`. Иначе квадрат потолка разгоняет кап и колонна улетает.

3 головы не увеличивают кап дня, но носят 3 сета — `party_power` выше.

Ориентир для **троих** (idle, слой 2): рекорд **100 за неделю**, **500 за месяц**, **3000 за квартал**. Соло медленнее на том же капе. Сет T1 у трио — около суток.

| Банда | Глубина | Кап зол/день | T слота (ilvl) | Цена слота | Зелье |
|------:|--------:|-------------:|----------------|-----------:|------:|
| 1 | 1–20 | 80 | T1 (4) | 48 | 6 |
| 2 | 21–40 | 160 | T2 (8) | 108 | 12 |
| 3 | 41–60 | 240 | T3 (12) | 181 | 18 |
| 4 | 61–80 | 320 | T4 (16) | 270 | 24 |
| 5 | 81–100 | 400 | T5 (20) | 377 | 30 |

Цена: `round(12 * (tier*4) * 1.12^(band-1))` при `tier = band`.

## 7. Catch-up

Кран игрока — `rate × Δt`.

PQ от `last_pq_ts` до `now`:

1. Начислить merc gold/XP одним `walk_capped_grant`.
2. Пройти целочисленные глубины вперёд от `last_d` (`walk_ts + t_eff`). Стены `d_max` нет.
3. На SHOP — автозакупки. На CITY — полный хил, лавка, 1 травма, запомнить чекпоинт. На COMBAT/BOSS — сток. На REST — 22% HP.
4. Wipe внутри сегмента: сохранить прогресс, спавн на `checkpoint_d`, продолжить. Кап wipe за sync = 24.

Первый запуск на старой колонне: `last_pq_ts = now` (историю не переигрывать).

## 8. Данные и API

Новые колонки: `companion_cards` и `delve_companions` — `level`, `xp_unspent`, `gold_wallet`, `power`, `hp_current`, `hp_max`.  
`delve_states` — `last_pq_ts`, `run_origin`, `wipe_count`, `pq_seed`, `pq_gold_today`, `pq_xp_today`, `pq_grant_day_msk`, `pq_last_cycle`, `pq_last_d`.

Таблицы: `delve_gear_templates`, `delve_companion_gear`, `delve_consumable_templates`, `delve_companion_bags`.

Флаг: `delve.pq_enabled` (default true). Новых POST нет.

`GET /delve/sync` добавляет на лицо: `level`, `power`, `gold_wallet`, `xp_unspent`, `hp_*`, `gear[6]`, `bag[]`, `last_shop_buy`; на корень: `party_power`, `d_max`, `wipe_count`, `pq_enabled`, `run_origin`.

## 9. Приёмка

- Покупка и заточка всегда увеличивают `power`.
- Витрина не содержит `ilvl <= current`.
- Wipe сохраняет экип/сумку/level/gold_wallet/xp, лечит HP, спавнит на последнем городе.
- `Player.gold` и XP ОВ не зависят от покупок наёмниц.
- Два прогона с одним Δt и сидом совпадают.
- Кадр PQ = `last_d`; `d_fair` не режет ходьбу.
- Город 40 — `CITY`, не босс. Костёр не лечит на 100%.
- За 24 ч банды B есть покупка и нет тира выше B+1.

## 10. Вне v1

Ручной магазин, разбор, пыль, боевые аффиксы ОВ на колонне, перенос в инвентарь ОВ, wipe ≠ смерть карточки, изменение капов крана игрока.
