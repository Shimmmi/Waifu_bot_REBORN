# PQ: класс, стойка, нрав, черты → сила, события, раны, тик узла

Слой поверх `DELVE_PROGRESS_QUEST_TZ.md`. Не арена, не `merc_perks`, не `expedition_perk_resolve`. Авто, детерминизм, два кошелька.

Канон: **класс — первичная боевая ось.** Стойка совпадает с классом почти всегда; её боевые числа не стакаются с классом. Нрав — узкая ось (инстинкт + мелкие моды). Черты — крючки с ценой.

---

## 0. Что меняется в часах

Сейчас спуск — пила: `t_down = 720·ln(1+d_max)` ≈ 26 мин при `d_max=8`. PQ при catch-up идёт по целым глубинам этой пилы.

**Новый канон PQ:** один узел хребта = один тик.

```
T_NODE = 30
T_eff  = clamp(round(T_NODE * (1 + tick_bonus_party)), 15, 50)   # секунды, int
t_down = T_eff * d_max
t_up   = 6                                                      # стена мира, без модов
t_rest = 50 + 10*ln(1+d_max)                                    # стена мира, без модов
```

Пила HUD живёт: `u = d/d_max` → «несут / вровень / тяжело». Время кадра узла = `T_eff`, не `720·ln`.

При `d_max=8`, `T_eff=30`: спуск 4.0 мин, первый гибкий узел на `d=1` через 30 с, первый правдоподобный бой (после zip) ≈ 90 с. Это сознательный сдвиг темпа. Сток **перетюнить** (разд. 8), иначе 5× узлов взорвут вайпы.

## 1. Законы стака (партия vs актор)

Две полки. Не смешивать.

### 1.1 Полка партии (одно число на узел)

Считается по **живым**. Мёртвая не тормозит и не лечит тик.

| Величина | Как стакается | Почему не сумма |
|----------|----------------|-----------------|
| `tick_bonus_party` | **среднее** `tick_bonus_i` | 3×осторожные не делают 50 с |
| `drain_mult` | **1 + среднее** `drain_bonus_i` | одна осторожная чуть бережёт всех |
| `injury_mult` | **1 + среднее** `injury_bonus_i` | шанс раны узла — общий; жертва потом |
| веса `monster/event/npc/empty` | **среднее** векторов, затем `max(4)` и нормализация | не голосование «кто громче» |
| `party_power_eff` | **сумма** `power_eff_i` живых | сила складывается, P3 жив |
| ауры хила (`rest_aura`) | **сумма** чужих аур на цель | целительница+певунья чувствуются |

### 1.2 Полка актора (своя карточка)

| Величина | Где | Стакан внутри актора |
|----------|-----|----------------------|
| `power_eff_i` | `d_max`, зазор стока, вес soak | **аддитив** бонусов, затем × `power_raw` |
| `shop_mod_i` | её лавка, её цена | аддитив, clamp |
| `rest_heal_i` | её реген на REST | аддитив self + ауры, clamp |
| `soak_i` | доля стока / шанс стать жертвой раны | аддитив |
| `leave` / crime / potion-порог | её события летописи | только её черты |

Внутри актора, в этом порядке:

```
bonus_i = class.x + temper.x + Σ trait.x + status.x
          + (stance.x  если стойка расходится с CLASS_TO_STANCE)
```

Тик / сток / рана — **аддитив бонусов**, не произведение. Проще клип, нет 1.18×1.10×1.06.

```
tick_bonus_i   = clip(Σ, −0.28, +0.28)
injury_bonus_i = clip(Σ, −0.32, +0.32)
drain_bonus_i  = clip(Σ, −0.22, +0.22)
B_power_i      = clip(Σ, −0.25, +0.25)     # на найме; статусы после найма могут до −0.40
```

Клип **на акторе**, потом среднее по живым. Три одинаковых осторожных = одна осторожная по темпу.

### 1.3 Двойной зачёт: класс XOR стойка

```
CLASS_TO_STANCE = {
  рыцарь/воин → shield,
  лучник/ассасин → scout,
  маг/целительница/торговка → guide,
}
```

- Есть `class_id` и `stance == CLASS_TO_STANCE[class]` → боевые числа и веса событий **только из класса**. Строка стойки = 0.
- Есть `class_id` и стойка **другая** (мастер, старый визард) → класс + стойка оба.
- Нет класса, только стойка → стойка первична, класс = 0.

Нрав **всегда**. Черты **всегда**. Не тянуть `merc_perks`.

### 1.4 Закон новичка

Случайный найм (класс 1–7 равномерно, 2 черты из 16 без антонима, нрав равномерно, стойка = классовая):

- `T_eff ∈ [24, 38]` не реже 95% бросков;
- `injury_mult ∈ [0.78, 1.22]`;
- `power_eff / power_raw ∈ [0.75, 1.25]`.

Экстремумы 15–50 с и «стекло vs крепость» — только собранная пати, не два случайных соло.

## 2. Формула тика и примеры

```
tick_bonus_i     = clip(class.tick + temper.tick + Σ trait.tick + status.tick [+ stance.tick], −0.28, +0.28)
tick_bonus_party = mean(tick_bonus_i по живым)
T_eff            = clamp(round(30 * (1 + tick_bonus_party)), 15, 50)
```

Нога-рана: `status.tick = +0.06` только у этой. Остальные статусы — разд. 6.

### 2.1 Соло: целительница, stay, осторожная + тихая

| Слой | tick | injury | drain | power B |
|------|-----:|-------:|------:|--------:|
| целительница | +0.06 | −0.05 | −0.06 | −0.04 |
| stay | +0.04 | −0.04 | −0.04 | 0 |
| осторожная | **+0.14** | **−0.16** | **−0.08** | 0 |
| тихая | 0 | −0.04 | 0 | 0 |
| **сумма** | **+0.24** | **−0.29** | **−0.18** | **−0.04** |

```
T_eff = round(30 × 1.24) = 37 с
P_раны COMBAT = 0.09 × (1 − 0.29) = 0.064
сток × 0.82
power_eff = 1 × 0.96 = 0.96
спуск при d_max=8: 8 × 37 = 296 с ≈ 4.9 мин
```

Осторожная **реально** тянет шаг (30→37) и режет раны (9.0%→6.4%). Не в два раза.

### 2.2 Соло: ассасин, curiosity, бесстрашная + хвастунья

| Слой | tick | injury | drain | power B |
|------|-----:|-------:|------:|--------:|
| ассасин | −0.08 | +0.05 | +0.06 | 0 |
| curiosity | −0.03 | +0.04 | +0.02 | 0 |
| бесстрашная | **−0.10** | **+0.10** | **+0.08** | +0.04 |
| хвастунья | −0.06 | +0.06 | +0.05 | +0.03 |
| **сумма** | **−0.27** | **+0.25** | **+0.21** | **+0.07** |

```
T_eff = round(30 × 0.73) = 22 с
P_раны COMBAT = 0.09 × 1.25 = 0.113
сток × 1.21
power_eff = 1.07
спуск d_max=8: 176 с ≈ 2.9 мин
```

Отношение к осторожной целительнице: тик 37/22 = **1.68×**, раны 0.113/0.064 = **1.77×**. Это края сборки, не случайный найм.

### 2.3 Трио смешанное (обязательный компромисс)

1. Рыцарь, stay, осторожная + верная  
2. Ассасин, curiosity, бесстрашная + хвастунья  
3. Целительница, stay, боится_тьмы + добрая  

Фонарь (разд. 5): живая целительница → у #3 `боится_тьмы.tick` 0.10→0.05, `power` 0, BOSS-шип ран слабее.

| # | tick | injury | drain | B_power | power_eff (raw=1) |
|--:|-----:|-------:|------:|--------:|------------------:|
| 1 | 0.04+0.04+0.14+0 = **+0.22** | −0.08−0.04−0.16−0.04 = **−0.32** | −0.10−0.04−0.08−0.04 = **−0.22** | 0.10+0.04 = **+0.14** | 1.14 |
| 2 | −0.08−0.03−0.10−0.06 = **−0.27** | 0.05+0.04+0.10+0.06 = **+0.25** | 0.06+0.02+0.08+0.05 = **+0.21** | 0.04+0.03 = **+0.07** | 1.07 |
| 3 | 0.06+0.04+0.05+0 = **+0.15** | −0.05−0.04−0.10+0 = **−0.19** | −0.06−0.04+0+0 = **−0.10** | −0.04+0 = **−0.04** | 0.96 |

```
tick_bonus_party = (0.22 − 0.27 + 0.15) / 3 = 0.033
T_eff            = round(30 × 1.033) = 31 с          # почти база
injury_mult      = 1 + (−0.32+0.25−0.19)/3 = 0.913
P_раны COMBAT    = 0.082
drain_mult       = 1 + (−0.22+0.21−0.10)/3 = 0.963
party_power_eff  = 3.17   (+5.7% к raw 3)
```

Одна осторожная **не** ставит трио на паузу. Бесстрашная не сжигает всех. Темп — торг.

## 3. Класс (первичная ось) — числа

Веса `monster / event / npc / empty` — **дельты** к базе гибкого узла (разд. 3.1). Сумма дельт ряда = 0.

| Класс | стойка | power | drain | tick | injury | shop | rest | soak | mon | ev | npc | empty |
|-------|--------|------:|------:|-----:|-------:|-----:|-----:|-----:|----:|---:|----:|------:|
| рыцарь | shield | +0.10 | −0.10 | +0.04 | −0.08 | 0 | +0.02 | +0.25 | +8 | −2 | −2 | −4 |
| воин | shield | +0.08 | −0.08 | 0 | −0.04 | 0 | 0 | +0.20 | +10 | −4 | −2 | −4 |
| лучник | scout | +0.02 | +0.02 | −0.06 | +0.02 | 0 | 0 | −0.10 | 0 | +2 | 0 | +6 |
| маг | guide | +0.04 | +0.06 | 0 | +0.06 | 0 | +0.04 | −0.05 | +4 | +8 | 0 | −12 |
| ассасин | scout | 0 | +0.06 | −0.08 | +0.05 | +0.02 | −0.04 | −0.18 | +6 | 0 | −2 | −4 |
| целительница | guide | −0.04 | −0.06 | +0.06 | −0.05 | 0 | **+0.25** | +0.08 | −8 | +2 | +4 | +2 |
| торговка | guide | −0.06 | +0.04 | +0.02 | +0.02 | **−0.10** | 0 | −0.05 | −6 | +2 | **+12** | −8 |

`rest` целительницы — self. Аура на других: `rest_aura = +0.10` (не пишет в её `rest`).

`shop` — множитель **цены** этой наёмницы: `price_eff = round(price × clamp(1+shop_mod, 0.78, 1.15))`. Отрицательный = дешевле.

`hp_max = 40+8×power_raw` — класс HP не раздувает. Танк живёт через drain/soak/injury.

Найм, raw=1, без черт/нрава: `power_eff` от 0.94 (торговка) до 1.10 (рыцарь). Внутри ±25%.

### 3.1 Гибкий узел (слой А)

Хребет **замок** не роллится: `SURFACE / BOSS / BRANCH / LANDMARK / REST / SHOP` как сейчас (`d%10`, `d%12==4`, …).

Только бывшие `TRAVERSE|COMBAT` — взвешенный выбор:

```
base = {monster: 40, event: 22, npc: 10, empty: 28}
если d < 0.35·d_max:  empty +15, monster −15     # zip
если d > 0.75·d_max:  monster +10, empty −10     # дно пилы
w = base + mean(дельты живых)
каждое w = max(4, w);  нормализовать;  pick(rng(pq_seed,"kind",cycle,d), w)
```

| kind | Узел PQ | Сток | P_base раны |
|------|---------|------|------------:|
| monster | COMBAT | полный | 0.09 |
| event | EVENT | 0 (или 50% COMBAT, если severity=maim в шаблоне) | 0.06 |
| npc | NPC | 0 | 0.02 |
| empty | TRAVERSE | 0 | 0.03 |

Замки:

| Узел | P_base раны |
|------|------------:|
| BOSS | 0.16 |
| REST | 0.02 |
| SHOP | 0.01 |
| BRANCH | 0.04 |
| LANDMARK | 0.03 |
| SURFACE | 0.00 |

```
P_injury = clip(P_base[node] × injury_mult, 0.005, 0.28)
hit = rng(pq_seed,"inj",cycle,d) < P_injury
victim = weighted_pick(living, soak_weight_i)
soak_weight_i = max(0.25, power_eff_i) × (1 + soak_i)
```

Слой Б (какой шаблон кадра) — существующие `prefer_stance` / `need_tag` / `prefer_temper`. Веса слоя А не подменяют каталог `delve_events.v1.json`.

Числа — вклад **одной** черты. Вторая просто плюсуется.

Пустые клетки весов = 0. Не перечисленные моды = 0.

### 5.1 Фонарь (боится_тьмы × целительница / певунья / суеверная)

`has_lantern` если среди живых есть хотя бы одно:

- класс целительница, **или**
- стойка guide (в т.ч. сама испуганная, если она guide), **или**
- черта певунья, **или**
- черта суеверная.

Целительница с `боится_тьмы` **сама себе фонарь**. Это синергия: тик +0.05 вместо +0.10, нет штрафа силы на дне, COMBAT injury −0.10, `leave_fear` ×0.5. BOSS без свиты всё ещё неприятный (+0.04 к ране, не +0.12).

Певунья в пати с испуганной лучницей (scout, не guide): фонарь от песни — та же таблица.

### 5.2 Жадная × торговка

```
shop_mod = −0.10 + −0.08 = −0.18  → clamp 0.78 → цена ×0.82
```

Зелья: кап 6, юз с 28%. Золото крана то же (стена), слот покупает чаще/дешевле, буфер HP тоньше. Не «просто богаче».

### 5.3 Целительница × добрая

```
heal_i = hp_max × 0.10 × (1 + rest_self) × (1 + Σ rest_aura_чужих)
heal_i = min(heal_i, 0.22 × hp_max)
```

Соло целительница+добрая+stay: `0.10 × 1.37 × 1.00 = 0.137` (кап не бьёт).  
Трио с певуньей: цель-не-хилер `0.10 × 1.xx × 1.23` (аура 0.10+0.08+0.05). Кап 0.22 не даёт полного отхила каждый костёр.

## 6. Сила: raw святой, eff для колонны

```
power_raw_i = level + Σ ilvl экипированных слотов          # как сейчас, P3/P4
B_i         = class.power + temper.power + Σ trait.power + status.power
              [+ stance.power если расхождение]
B_i         = clip(B_i, −0.25, +0.25)                      # на расчёте найма
              после статусов clip(B_i, −0.40, +0.25)
power_eff_i = power_raw_i × (1 + B_i)                      # float, не round
party_power_eff = Σ power_eff_i живых
d_max       = floor(8 + 0.35 × party_power_eff)
gap         = max(0, d − party_power_eff)
```

**P3 не ломать:**

- витрина смотрит `ilvl` и `power_raw`, не `power_eff`;
- после экипа/заточки `power_raw` строго растёт → `power_eff` тоже (`1+B > 0` всегда);
- HUD карточки: «сила» = raw; колонна/сток/`d_max` едят eff.

Покупка на торговке с B=−0.06: `ilvl +4` → raw +4 → eff +3.76. Всё равно плюс. Рыцарь с тем же слотом: +4.40. Слот дороже не становится от класса; глубина чуть разная.

### 6.1 Статусы (после найма)

| Статус | power | tick | injury | drain | Примечание |
|--------|------:|-----:|-------:|------:|------------|
| рана рука/лицо/рёбра/глаз | −0.08 | 0 | +0.04 | +0.03 | soak не менять |
| рана нога | −0.08 | +0.06 | +0.04 | +0.03 | тик только этого актора |
| trauma ярость | 0 | −0.03 | +0.05 | +0.03 | |
| trauma боится_тьмы | как черта ×0.5 если черты нет; если черта уже есть — не удваивать, шип BOSS +0.04 | | | | |
| trauma вина / страх | 0 | +0.03 | 0 | 0 | rest −0.04 |

Приёмка ±25% — **в момент найма**, без ран. После похода eff может просесть — это рана, не сломанный P3.

## 8. Стена мира vs тик узла

Это закон экономики. Нарушил — осторожная голодает игрока или бесстрашная печатает слоты.

### 8.1 Только стена мира (`rate × Δt`, кап дня МСК)

| Поток | От `T_eff` | Почему |
|-------|------------|--------|
| `Player.gold` (кран L6/L8/L12) | **нет** | пол ОВ; смотришь/нет, тик любой |
| XP основной вайфы с колонны | **нет** | тот же `walk_capped_grant` |
| `gold_wallet` / `xp_unspent` наёмниц | **нет** | кап дня от банды, не от числа лавок |
| `t_up`, `t_rest` поверхности | **нет** | монтаж и лагерь не «осторожничают» |
| сутки капа, `wipe_count` день, `run_origin` после вайпа | **нет** | |
| catch-up игрока: `grant = rate × (now−last_grant)` | **нет** | считать **до** или **после** узлового цикла, отдельным проходом |

Осторожная на 37 с **не** режет `Player.gold`. Бесстрашная на 22 с **не** ускоряет пол.

### 8.2 Только тик узла (`T_eff`)

| Поток | Следствие медленного тика | Следствие быстрого |
|-------|---------------------------|-------------------|
| Число узлов / боёв / лавок / костров | меньше в час | больше в час |
| Сток, раны, wipe | реже | чаще |
| Автопокупка, заточка, зелья | реже визитов; **кошелёк наёмницы полнее** к лавке | чаще визитов; золото тоньше, больше трат на пот |
| `d` внутри цикла, театр кадров | медленнее кино | быстрее кино |
| `d_max` | не от тика; от `party_power_eff` | то же |

Золото наёмниц копится от стены. Осторожная приходит на SHOP реже и **платит тот же прайс-лист** (кроме shop_mod). Она не беднее — она реже кликает витрину. Бесстрашная кликает чаще и сжигает пот.

### 8.3 Catch-up узла (детерминизм)

```
t = last_pq_ts
пока t + T_eff(state) ≤ now и wipe_in_sync < 24:
    обработать один узел хребта   # сток/лавка/хил/ролл kind
    t += T_eff(state)             # T_eff пересчитать после смертей
    если wipe:
        t += t_rest               # стена, без черт
        run_origin = t; HP = max
last_pq_ts = t                    # хвост < T_eff не терять
```

`T_eff` внутри цикла меняется, если живые сменились. Сид тот же → те же узлы.

Кран игрока **не** входит в этот цикл.

### 8.4 Перетюнинг стока под `T_NODE=30`

Старые `4+0.45·gap` / `10+0.7·gap` при 4-мин спуске вайпят каждые ~8 мин. Нельзя.

Новые константы (дефолт без крайних черт, найм power_eff≈1, `d_max=8`):

```
drain COMBAT = max(1, round(1.2 + 0.18 * gap))
drain BOSS   = max(1, round(3.0 + 0.28 * gap))
REST regen   = 0.10 * hp_max          # потом × rest_mod, кап 0.22
```

Ориентир найма: вайп раз в **40–70 мин** стены, не раз в 8. Зелья/костёр как сейчас по порогам, кроме жадной.

Сток по-прежнему режется на живых **пропорционально `power_eff` × (1+soak)**, не raw.

## 10. Порядок резолва узла (для сима, не код)

1. Живые → `T_eff`, `party_power_eff`, `d_max`, веса kind, `drain_mult`, `injury_mult`.  
2. Тип: замок хребта или ролл kind.  
3. Левелап (как сейчас).  
4. Если SHOP — автопокупка **этой** карты по её `shop_mod` и жадным капам.  
5. Если COMBAT/BOSS — сток × `drain_mult`, делёж по soak.  
6. Если REST — хил по `rest`+ауры.  
7. Бросок раны; жертва по soak.  
8. Слой Б: шаблон кадра ( tegи / стойка / нрав ).  
9. Авто-пот как сейчас (жадная — порог 28%).  
10. Wipe → HP max, глубина 0, кошельки живы, ждать `t_rest` стены.

## 11. Что не делать

- Не множить кран игрока на `30/T_eff`.  
- Не суммировать `tick_bonus` трёх тел.  
- Не вешать боевые моды стойки на классовую стойку.  
- Не считать `power_eff` в правиле «слот хуже текущего».  
- Не тащить перки арены.  
- Не давать осторожной минус к стоку **и** минус к тику без цены: цена — время.  
- Не клипать партию в 15–50 **до** среднего: клип на акторе, среднее, затем clamp тика.
