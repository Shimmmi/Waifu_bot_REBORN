# Живые наёмницы — таверна + летопись колонны

Внутренняя спека. В UI не копировать законы как подсказки «успей».
Пила, кран, капы — `docs/VARIANT_2_2_POGRUZHENIE.md`. Роль колонны — `docs/DELVE_ROLEPLAY.md`.
Критик RimWorld/DF: **9.1/10** (законы ниже обязательны; срыв сборки = снова 8.x).

Арена, ops, скамейка, обмен, 4 дневных слота найма — **вне**.

## Одна фраза

Одни и те же 0–3 лица сидят в таверне и ходят в колонну. Колонна идёт без игрока. Истории пишет стол. Раны кусают завтрашнюю летопись, не золото/час.

## Слои

1. **Кран** — золото и XP основной вайфу от времени. Кап дня жив. Размер отряда не множит кран (`1 = 2 = 3` голов). Лояльность к патрону может поднять cap.
2. **Театр** — пила и хребет узлов. Строка «Спуск · несут / вровень / тяжело» — погода пилы.
3. **Летопись** — такты стола. `GET /delve/sync` без LLM.

`gold_delta` / `xp_delta` механически **0**. Проза может солгать про горсть. Два профиля, одно Δt, одно золото.

## Законы

| L-ledger | Кошелёк = кран. Пустой стол `loyalty_mult = 1.0`. Лояльность к патрону может поднять дневной cap/rate до 1.40. Не `party_mult` с голов. |

| L-fire | Уволить из модалки. 1 раз в сутки МСК (админ без лимита). Без `beat_id`. Самоуход лояльности 0 слот не ест и траур не ставит. |

| L-last | Последнюю живую AFK не убивать. Max 3. |

## Карточка

Слоты 1–3 = колонна. Не `HiredWaifu`.

Поля: имя, стойка, нрав, 2 черты, плащ, Look Card, био (заморозка), 2:3 аниме + 1:1 пиксель (один канон), слоты плоти (≤3) и рассудка (≤3), теги похода, связи, журнал append-only.

В модалке — человек: качественные раны, следствия по имени («Сера не смотрит»), не BR и не +ATK.

Миграция: `delve_companions` → карта, пиксель как есть, 2:3 в очередь, раны пустые.

## Такты

Такт, когда с прошлого такта прошло ~2 ч **и** тип узла сменился (или узел особый: лавка, босс, метка, костёр, вилка). На sync: до 48 тактов по порядку.

Каталог: `data/delve_events.v1.json`.

Зубы: веса следующих строк, `leave_column`, шрам на рамке, связи. Игрок веса не видит.

## Таверна

Одна зала. Вкладки Найм/Отряд/Арена/Обмен/Инвентарь мертвы. BGM — чердак.

Три колонны: рамка над капюшоном. Пустой стул после смерти/ухода = поминовение. Когда траур кончился — «вошла с дождя». Увольнение только в модалке.

Чат: preset `fast` (`google/gemini-3.5-flash-lite`), on-demand, sore spots, лимит реплик.

Мобильная «Таверна» → `tavern.html`, не экспедиция.

## Найм

Механика → Look Card → JSON имя/био/голос → 2:3 → 1:1 с референсом. Найм не падает, если арт упал. Реген арта только при смене силуэта.

## Не делать

`party_mult` на кран, HP-бар на стволе, кнопка лечить, витрина редкости как сила, второй idle, LLM в `GET /delve/sync`, пуши, скамейка, арена.
