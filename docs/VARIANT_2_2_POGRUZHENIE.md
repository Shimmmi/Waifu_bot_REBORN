# VARIANT 2.2-C — «Погружение вглубь»

**Progress Quest + визуальный язык PoE Delve · один сайд-айдл · кран O(1) · театр = rng(seed, depth(t))**

Статус: spec only.  
Итерация: **2.2-C** (патч после критика 2.2-B). 2.2-A и 2.2-B отбракованы.

---

## 0. Одна фраза

Отряд из 1–3 пиксельных спутниц **сам** спускается по колонне. Золото и XP ОВ капают от **времени**, как пол — не зарплата. Колонна — кино: `depth(t)` из сида. Ветка красит тоннель. Смотришь или нет — **цифры те же**.

Это **единственный** сайд-айдл. Он **заменяет** экспедиции, таверну наёмниц и арену. Не параллелится с ними.

## 1. Законы (нарушил — режим сломан)

| # | Закон |
|---|--------|
| **L1** | Хребет ≠ хрома. Тип узла и кадр театра = `d` + сид. Ветка не входит в кран и не входит в PB. |
| **L2** | Симуляция не ждёт игрока. Нет `WAITING_FOR_PLAYER`. |
| **L3** | Инстинкт уже выбран. Клик игрока только красит. Нет countdown. Нет FOMO-копирайта «успей». Away → Инстинкт, тик не стоит. |
| **L4** | Жар — внутренний параметр театра, авто. Не энергия игрока. Не HUD-полоска. |
| **L5** | Отряд 1–3 создаётся один раз. Нет скамейки, нет гачи. |
| **L6** | Кран не привязан к узлу. Нет «успей забрать сундук». |
| **L7** | `watching_mult = 1`, `branch_mult = 1`, `size_mult = 1`. |
| **L8** | Кран O(1) от стены мира. Театр O(1) от `t`. Нет поузлового catch-up. |
| **L9** | **Один сайд.** Заменяет экспедиции, таверну наёмниц, арену. Не параллелится. |
| **L10** | Реликвии/вешки/«находки» = журнал, **0 силы**. Нет сумки, нет сравнения, нет разбора. |
| **L11** | Титулы = **0 силы**. |
| **L12** | `gold_cap_day ≤ 0.25 × chat_daily_gold_cap`. Пол. После капа кран = 0, кино идёт. |
| **L13** | Нет второй валюты (пыль эха, уголь цикла, азурит). Косметика — автоанлок. |
| **L14** | Пуши колонны default **off**. Нет notify-типа «ветка». |

- **A:** пауза на вилке, магазин-скилл, вайп сумки.  
- **B:** закрыла EV-ветки, но оставила *второй Diablo* (реликвии+ранги), полоску-кнопку, силу титулов, параллель с экспедициями, поузловой кран, пыль как валюту, кап уровня зарплаты экспедиций.

## 2. Место в REBORN — один сайд

| Режим | Статус после 2.2-C |
|--------|-------------------|
| Соло / чат-данж, экип ОВ | **Основной** цикл. Жив. |
| GD / гильдия | **Социал.** Жив. Не айдл-сайд. |
| Бездна | **Энгейм ОВ**, активный. Жив. Не сайд-айдл. |
| Экспедиции | **Sunset.** Слоты, claim, тики — выключены. |
| Таверна наёмниц (найм, скамейка, перки похода) | **Sunset.** Нет второго ростера. |
| Арена наёмниц | **Sunset.** |
| **Погружение** | **Единственный сайд-айдл.** Кормит ОВ полом. Спектакль — колонна. |

Дверь старой таверны в городе **становится входом в лагерь колонны** (не второй простой). Игрок не видит два айдл-крана.

Открытие: 1 закрытый соло-данж **или** уровень ОВ ≥ 5. Не с титульного экрана.

Отряд колонны — единственные лица игрока кроме ОВ. Это не наёмницы: созданы раз, пиксель JRPG, не продаются.

## 3. Два слоя (главный архитектурный патч)

### 3.1 Кран (экономика) — O(1)

Пусть `Δt` — секунды стены мира с прошлого начисления (включая оффлайн).

```
rate_gold = k_g * ov_gold_scale(ov_level)     # НЕ от глубины, НЕ от размера отряда, НЕ от «реликвий»
rate_xp   = k_x * ov_xp_scale(ov_level)

grant_gold = min(cap_gold_left_today, rate_gold * Δt)
grant_xp   = min(cap_xp_left_today,   rate_xp   * Δt)

cap_gold_day ≤ 0.25 * chat_daily_gold_cap(ov)    # якорь: chat_reward, не экспедиции
cap_xp_day   ≤ 0.15 * typical_solo_xp_day(ov)    # ещё тоньше: XP не должен обогнать чат-данж
```

После капа: `grant = 0`. Колонна **не стопает**. Нет конвертации в пыль.

Нет материалов из колонны (это был бы второй кран). Нет предметов с аффиксами.

Тест: два профиля, один heartbeat, другой 3 дня оффлайна, один сид, одно `Δt` — золото/XP совпадают с точностью округления.

### 3.2 Театр (колонна) — O(1) кадр

Не симулировать циклы. Не суммировать drain по узлам.

Невидимый параметр (не UI, не сумка):

```
A = hours_in_column          # стена мира, AFK капает
d_ceiling(A) = D0 * (1 + α * ln(1 + A)) * (1 + 0.03 * sqrt(ov_level))
```

Пила глубины (лагерь → спуск → отход → лагерь):

```
T_down  = t0 * ln(1 + d_ceiling)      # длиннее кино, когда «сильнее», не жирнее кран
T_up    = 6 с                         # монтаж подъёма для смотрящего; away: кадр сразу лагерь
T_rest  = 50 + 10 * ln(1 + d_ceiling)
period  = T_down + T_up + T_rest
phase   = (now - t_origin) mod period

if phase < T_down:
    u = phase / T_down
    depth = 1 + (d_ceiling - 1) * u^1.15      # чуть быстрее вначале (zip), вязче у дна
    state = DESCENDING
elif phase < T_down + T_up:
    depth = lerp(d_peak, 0, ...)
    state = ASCENDING
else:
    depth = 0
    state = SURFACE_REST
```

Кадр узла:

```
d = floor(depth)
node = spine(spine_seed, d)                # таблица типов, O(1)
chroma = committed_chroma(segment)         # Инстинкт или тихий клик, 0 EV
event_key = rng(spine_seed, cycle_index, d)
```

Catch-up: одно вычисление `A`, `depth(now)`, `state`; кран = `rate × Δt`. **Нет цикла `for node in history`.** Нет LLM на историю.

«Каждый цикл сильнее» = `d_ceiling` растёт с `A`. Это видно как более глубокое кино и более дальний фонарь эха. Это **не** второй боевой гринд.

`A` не показывается как «опыт колонны» с бар-кнопкой. Игрок видит: PB глубины, ярче память карты, дальше туман.

## 4. Визуальный язык

Тот же Delve-ствол + PQ-жетон, что в B, с тремя вырезами:

1. **Нет полоски Жары** на главном кадре.  
2. **Нет «реликвии 3/6».**  
3. **Нет «+36 зол.» на карточке узла** (это лгало бы, что узел платит).

### 4.1 Кадр

- Вертикальный ствол, фонарь отряда (авто).  
- Вьюпорт ~14 узлов, текущий в нижней трети.  
- Два рукава сходятся каждые 5 глубин (хрома, не длина).  
- Память: тусклый контур типов на уже виденных `d` (только вид).  
- Фонарь эха на личном PB.

### 4.2 Жетон

Пиксель 32×48. 1 / 2 плечом / 3 треугольником. Tween шага, удара, костра, поворота к Y, подъёма. Размер отряда **только это**.

### 4.3 Иконки узлов

Бой, переход, отдых, лавка-виньетка, Y, вешка, босс (`d % 10 == 0`), лагерь. Цвет = хрома, форма = хребет.

### 4.4 HUD-статус (не полоска)

Одна строка, без процентов:

| state | Строка |
|-------|--------|
| zip (`d ≪ d_ceiling`) | «Спуск · несут» |
| середина | «Спуск · вровень» |
| дно пилы | «Спуск · тяжело» |
| подъём | «Наверх» |
| лагерь | «Лагерь · сами пойдут» |

Жар как число, `V`, drain — **только лист лога** (тап «лист», вторичный экран). Главный экран не предлагает «следить за HP».

Кран на HUD: мелкий нейтральный drip в сводке, **не** привязанный к удару: «пол дня: 18%» или ничего, пока не откроешь лист. Предпочтение: **не показывать золото на колонне вообще** — оно в кошельке ОВ, как idle-пол. Колонна = кино.

## 5. Хребет и хрома

### 5.1 Хребет

```
d == 0            SURFACE
d % 10 == 0       BOSS
d % 5 == 0        BRANCH
d in LANDMARKS    LANDMARK      # 7, 13, 23, 37, 47, 67, 83, 97…
d % 8 == 6        REST
d % 12 == 4       SHOP_VIGNETTE
d < 0.35*d_ceiling TRAVERSE     # верх пилы выглядит zip
else              COMBAT
```

Тип узла не меняет кран. Нужен для кадра и шаблона фразы.

### 5.2 Хрома

6 равных палитр: грибы / кристалл / уголь / мокрое эхо / пепел / известняк. Журнал штампов, цвет тумана, имя врага. 0 силы.

### 5.3 Инстинкт

```
weight = 1 + 0.35*curiosity + 0.20*temper + 0.10*stay
```

Детерминирован. Default **уже подсвечен** на Y. AFK закрывает журнал за счёт curiosity.

## 6. Узлы как театр (0 силы)

Все кадры. Ни один не вызывает `grant_gold`.

**Бой / переход / отдых** — анимация + шаблон. Отдых на пиле совпадает с фазой, когда `state` ещё DESCENDING, но узел REST: костёр-кадр, не «ты выбрал хил».

**Лавка** — виньетка. «Купили безделушку.» Штамп журнала, если первый раз на этой `d`. Нет угля, нет трёх карточек, нет heat. Не магазин игрока.

**Развилка** — Y, Инстинкт-рукав **уже выбран**. Тихий клик по другому рукаву = хрома следующего сегмента. Если не кликнул — ничего не меняется (Инстинкт и так стоял). Нет часов, нет «5:00», нет пыли-таймера, нет модалки, нет красного. Окно = пока жетон на этом узле в театре; прошли — голос на следующую Y.

**Вешка** — штамп журнала (бывшая «реликвия»). Имя от хромы, id от `d`. 0 силы. Авто. Всплывает в журнале, не в сумке.

**Босс** — крупный кадр, фраза. Если пила разворачивает подъём на боссе — «срыв» как штамп и текст. Не режет кран. Не режет PB (PB = max `d_ceiling` / max достигнутый `floor(depth)` по формуле, одинаков для 1 и 3).

**Лагерь** — костёр, строка «сами пойдут». Нет skip.

## 7. Жар, отход, wipe — театр

Жар **существует** как внутренний `V_display = 1 - (depth / d_ceiling)` на спуске, чтобы лист лога мог показать «тяжело». Это не ресурс игрока и не рычаг крана.

Отход = фаза `ASCENDING` пилы. Авто. Нет кнопки «ещё чуть-чуть».

Wipe как failstate **удалён**. «Срыв» = штамп, если разворот пилы попал на босс-кадр. Сумки нет. Кран не знает об этом.

Что «остаётся» между циклами кино: `A`, PB, журнал, титулы (0 силы), память контуров. Что «сгорает»: текущая хрома сегмента, кадр глубины. Нет run-heat, нет угля, нет реликвий-предметов.

## 8. Прогрессия кроме уровня ОВ (без второго Diablo)

| Слой | Видно игроку | Сила |
|------|----------------|------|
| Уровень ОВ | основной профиль | мягко в `d_ceiling` и в `rate` крана (как и всё в игре) |
| **A, часы в колонне** | **не бар**, косвенно: глубже кино, дальше туман | только театр `d_ceiling` |
| Память карты | контуры узлов | 0 |
| Журнал (вешки, палитры, «реликвии») | штампы | **0** |
| Титулы | профиль ОВ | **0** |
| Строфа / связи | свечение трио, позы | **0** |
| Размер 1–3 | число спрайтов | **0**; PB тот же |

Никаких 6 слотов, рангов, «3 броска/день», сравнения двух сердец.

Формула силы отряда как боевого DPS **удалена** из экономики. `P` не нужен крану. Для строки «несут / вровень / тяжело» достаточно позиции на пиле: верх / середина / дно.

## 9. Развилка без FOMO (подтверждение)

Оставляем глагол **только** потому что:

- default = Инстинкт, уже выбран;  
- клик не меняет EV (L1, L7);  
- без клика поведение = AFK.

UI:

- рукав Инстинкта подсвечен;  
- второй рукав можно ткнуть, как сменить палитру обоев;  
- **никакого countdown** (ни красного, ни пыли, ни «5 мин»);  
- копирайт: «Можно подкрасить. Отряд уже идёт.» — без «успей», без «или авто»;  
- вкладка скрыта → голос сброшен, Инстинкт.

5-минутное окно **удалено как механика**. Оно было формой ожидания даже без паузы сима.

Пуш: не слать. Типа события «branch_choice» в notify-prefs нет. Все пуши колонны в префах **выключены с завода**; даже если игрок включит «колонна» (если такой тумблер вообще будет — только «вернулись на PB», и то default off), ветки в списке нет.

## 11. Кран vs чат (пол)

Якорь — **чат**, не мёртвые экспедиции.

```
cap_gold_column ≤ 0.25 * chat_daily_gold_cap
```

При текущем порядке чата (~очки дня → золото) это **пол**: оффлайн не голодает, чат-данж остаётся зарплатой экипа.

XP колонны ещё злее: ≤ 15% типичного соло-дня, чтобы уровень ОВ не качался «вкладкой в кармане» быстрее, чем чатом.

После капа: кино, журнал, PB. Пустота в кошельке — честно. Нет пыли, нет магазина косметики. Рамки/позы **сами** на порогах PB и штампов.

Престиж крошечной базы: PB + титулы (0 силы) на профиле. Нет арены. Нет сезонного ladder.

## 13. Почему смотреть весело

1. Жетон ползёт.  
2. Строка «тяжело» у дна пилы — напряжение без HP-кнопки.  
3. Босс-кадр каждые 10, штамп вешки, вспышка PB.  
4. Характер в одной фразе. Инстинкт озвучен.  
5. Подъём → костёр → снова вниз, карта чуть читаемее.  
6. Подкрасить Y, если сидишь. Нет долга.

Золото при этом капает в ОВ, как дождь за окном — не как лут с этого клыка.

## 15. Catch-up и LLM

```
on_request(now):
    dt = now - last_grant_ts
    gold/xp = min(cap_left, rate * dt)     # O(1)
    A += dt_hours
    render theater at now                  # O(1) пила + spine(d)
    last_grant_ts = now
```

Нет worker, который крутит узлы за 3 дня. Worker не обязателен: достаточно GET и редкого cron «подкрутить last_ts», если нужна онлайн-лента без открытия вкладки — всё равно O(1).

LLM:

| Когда | Что |
|-------|-----|
| Away | 0 |
| Открыл после оффлайна | 1 абзац-сводка + 1 кадр сейчас |
| Live | 10% кадров, 1 фраза, кэш `(seed, d, chroma)` |
| Вилка | шаблон нрава, 0 LLM |

## 16. Автомат (театр, не экономика)

## 18. Самооценка

| Критерий (вес) | B | **C** |
|----------------|---|-------|
| Idle EV AFK=active (18%) | 9.8 | **9.9** |
| Один сайд, не параллель (10%) | 6.0 | **9.7** |
| Нет второго Diablo-багa (10%) | 6.5 | **9.8** |
| Спектакль без HP-кнопки (12%) | 8.0 | **9.4** |
| Развилка без FOMO (10%) | 9.4 | **9.8** |
| Кран = пол vs чат (12%) | 7.5 | **9.6** |
| Catch-up O(1) vs Бездна (10%) | 8.0 | **9.7** |
| 1=3 EV (6%) | 8.2 | **9.9** |
| Delve-антипаттерны (6%) | 9.6 | **9.7** |
| Реализуемость (6%) | 8.8 | **9.5** |

**Взвешенно B ~8.3 после честного учёта пуль критика. C: 9.68.**

Слабое место C (не ниже 9.5): театр **отвязан** от золота — игрок может спросить «зачем босс, если не платит?». Ответ в тоне Progress Quest: босс — кадр, пол капает сам; смотреть — чтобы увидеть *свой* PB и лиц. Если продюсер потребует снова писать «+36» на клыке — режим откатится в B и умрёт от тех же пуль.

Долг до 9.8: шесть палитр равной плотности штампов; пиксель-пайплайн; sunset-план таверны без сиротских экранов.

## 19. Глоссарий

| Термин | Смысл |
|--------|--------|
| Кран | O(1) золото/XP от времени, кап vs чат |
| Театр | пила `depth(t)`, хребет, хрома |
| A | часы в колонне, невидимый потолок кино |
| Журнал | штампы вешек/палитр, 0 силы (бывшие реликвии) |
| Инстинкт | default-рукав, уже выбран |
| Лист | вторичный лог с цифрами Жары |
| Пол | кап ≤ 25% чата, не зарплата экспедиций |
| Sunset | экспедиции, найм, арена — выключены |
