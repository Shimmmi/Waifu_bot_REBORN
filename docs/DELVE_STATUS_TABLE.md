# Статусы наёмниц — каталог для оценки

Живая карта (`CompanionCard`) и колонна. Слоты 1–3 — не `HiredWaifu`.

Связанные документы: [TAVERN_LIVING_COMPANIONS.md](TAVERN_LIVING_COMPANIONS.md), [DELVE_PROGRESS_QUEST_TZ.md](DELVE_PROGRESS_QUEST_TZ.md), [DELVE_ROLEPLAY.md](DELVE_ROLEPLAY.md).  
Канон ран в коде: `src/waifu_bot/game/delve_pq_layer.py` (`STATUSES`). Летопись: `data/delve_events.v1.json`.

Каждая сущность помечена **в коде** или **только спека**. Числа в блоках «в коде» — из `StatusDef` / актуальных таблиц, не из старых p_C процентов.

## Как читать

Слои на одной карте (не смешивать):

| Слой | Где лежит | Потолок | Ключ |
|------|-----------|---------|------|
| Жизненный цикл | `companion_cards.status` | 1 | — |
| Плоть | `flesh[]` JSONB | 3 | `part` (рука / нога / лицо / глаз / рёбра) |
| Рассудок | `psyche[]` JSONB | 3 | `facet` (страх / ярость / вина / боится_тьмы) |
| Черты | `traits[]` | 2 при найме | имя черты |
| Теги похода | `adventure_tags[]` | растёт с травмами | грань |
| Связи | `relations` `{card_id: int}` | по живым | id соседки |
| Лояльность | `look_card.loyalty` | 0–100 | патрон |
| Чипы отряда | `PqParty.chips[]` | на партии, не на карте | bleed / poison / ward / limp |

Слот плоти/ума:

```
{id, part|facet, severity, permanent, returns_left}
```

`severity` в сейве: `царапина` / `рана` (`увечье` читается как серьёзная). HUD-ступень в коде: **лёгкая** / **серьёзная**. Критическая и перманентная — **только спека**.

Повтор по ключу не плодит второй слот: сильнее заменяет слабее; та же лёгкая — 40% эскалация, если есть запись в `ESCALATE`.

## Законы (спека S1–S8) и формулы

Канон баланса из ТЗ колонны. Что из этого уже в симе — в § «Как вешается». Что нет — в § «Расхождения».

| # | Закон |
|---|--------|
| **S1** | Два вреда. PQ HP — ресурс спуска. Flesh/psyche — память карты. Wipe, зелье и мазь наполняют HP. Статусы с этого не снимаются. |
| **S2** | Цель — лицо, цена — колонна. `% силы` бьёт power этой карты. Tick и drain складываются по отряду. |
| **S3** | Один ключ — один слот. Эскалация вверх, слабый удар игнор. |
| **S4** | Потолок 3 плоти + 3 рассудка на карту. |
| **S5** | Лесенка = сила + срок. Лёгкая сгорает у костра. Серьёзная живёт N городов. Крит/перм — спека. |
| **S6** | Кран игрока свят. Статусы не трогают `Player.gold` и XP ОВ. |
| **S7** | Честный чип: имя + срок + одно предложение. |
| **S8** | Один бросок на тип на узел. Спека считала COMBAT/BOSS/TRAVERSE. Код бросает на PQ-узел MONSTER/EVENT/NPC/BOSS, цель — одна живая. |

```
effective_power(card) = max(1, round(card.power * (1 + Σ power)))
tick_mult             = clamp(1 + Σ tick, 0.82, 1.40)
drain'                = drain * clamp(1 + Σ drain, 0.75, 1.55)
```

`tick > 0` — колонна ползёт. `tick < 0` — быстрее (ярость).

## 1. Жизненный цикл карты — в коде

`CompanionCard.status`. Чат: только `living` и `rain`.

| id | Кто видит | В колонне | Как попасть | Куда уходит | Траур |
|----|-----------|-----------|-------------|-------------|-------|
| `living` | за столом | да | найм, снять капюшон | left / fallen / dismissed | — |
| `rain` | «Вошла с дождя» | нет | после траура | living или refused | — |
| `refused` | архив | нет | отказ у двери | конец | да (новый траур) |
| `left` | ушла | нет | `leave_column`, лояльность 0, сверка призрака | можно уволить | да, кроме ухода по лояльности |
| `fallen` | погибла | нет | исход `death` | архив | да |
| `dismissed` | уволена | нет | кнопка в модалке | архив | да, если была living |

Флаги рядом (не `status`):

| Поле | В коде | Когда |
|------|--------|-------|
| `asked_to_leave` | да | такт `ask_leave` |
| `scar_frame` | да | любая injury; **не снимается** |
| `look_card.silhouette_dirty` | да | рука / нога / лицо / глаз |
| `can_dismiss` | считаемый | living + слот суток (админ без лимита); `left` всегда |

## 3. Как вешается и снимается — в коде

### Навешивание

1. **PQ** `roll_trauma()` один раз на узел, цель — одна живая. Шансы `(плоть, ум)`:

| kind | Плоть | Ум | Доля серьёзной (плоть / ум через `TRAUMA_GRADE`) |
|------|------:|---:|--------------------------------------------------|
| MONSTER | 9% | 2.5% | 20% / 20% |
| EVENT | 5% | 2% | 12% / 12% |
| NPC | 0 | 3% | — / 12% |
| BOSS | 16% | 7% | 30% / 30% |
| EMPTY / FIND | 0 | 0 | — |

Веса частей (плоть):

| kind | рука | нога | лицо | глаз | рёбра |
|------|-----:|-----:|-----:|-----:|------:|
| MONSTER | 30 | 14 | 18 | 10 | 28 |
| EVENT | 15 | 50 | 5 | 20 | 10 |
| BOSS | 24 | 10 | 16 | 14 | 36 |

Веса граней (ум):

| kind | страх | ярость | вина | боится_тьмы |
|------|------:|-------:|-----:|------------:|
| MONSTER | 30 | 40 | 10 | 20 |
| EVENT / NPC | 30 | 10 | 20 | 40 |
| BOSS | 35 | 20 | 15 | 30 |

Grace: пока `wipe_count = 0` и у партии `< 20` узлов, доля серьёзной ×0.35. Если у цели `< 15` узлов (`nodes_seen` на мерке), серьёзная ещё раз может скатиться в лёгкую.

2. **Летопись** `apply_outcome` injury/trauma → `TEMPLATE_STATUS`.
3. **`apply_status`**: тот же ключ — серьёзная бьёт лёгкую; две лёгкие — 40% `ESCALATE`; слотов 3 — лёгкая игнор, серьёзная вышибает самую слабую лёгкую.

`permanent: true` в схеме есть. Живого пути выставить нет (только сохранить при миграции старого ряда).

### Снятие

| Механика | Лёгкая | Серьёзная |
|----------|--------|-----------|
| REST (`heal_light`) | снять все | оставить |
| SURFACE / wipe (`tick_city_return`) | снять | `returns_left − 1`; 0 → снять |
| Город (`heal_one_trauma`) | снять одну (сначала лёгкую) | иначе −1 возврат |
| Целительница в городе (`healer_city_extra`) | — | −1 возврат у первой найденной |
| Такт `heal` | рана → царапина или снять царапину (последний слот плоти) | то же |
| Такт `heal_psyche` | pop последнего рассудка | то же |
| Зелье / мазь / wipe HP | не трогает статусы | не трогает |

HUD-хвост (`status_tail`): лёгкая → «до костра»; серьёзная → «1 город» / «N города».

## 6. Теги похода — в коде

`adventure_tags[]`. Chronicle `trauma` дописывает грань (`страх` / `ярость` / `вина` / `боится_тьмы`), если её ещё нет.

`_card_tags()` = черты + эти теги + psyche facets. От этого зависят `need_tag` шаблоны (`fear_dark`, `leave_fear`, `count_coins`, `crime_steal`).

В модалке тег `боится_тьмы` даёт чип «Просит не гасить», даже без слота `dark_ask`.

## 8. Связи и лояльность — в коде

**Связи.** `relations[other_id] += bond` (±1 с тактов `bond_look_away`, `bond_share_cloak`, `grudge_shop`). UI: «Имя — холодно / тепло / нейтрально» (<0 / >0 / 0).

**Лояльность.** `look_card.loyalty`, старт 50. Чат раз в сутки МСК: delta ∈ {−1, 0, +1}. 0 → `left` без траура и без слота увольнения. Кран: лояльность может поднять дневной cap до 1.40×.

| Диапазон | Сердце |
|----------|--------|
| 0–5 | `broken` |
| 6–30 | `dim` |
| 31–69 | `pink` |
| 70–99 | `red` |
| 100 | `gold` |

## 9. Журнал — в коде, не слот

Сухие факты `JOURNAL_KINDS`. Бытовые `beat` / `legend` в модалку не идут.

`injury` `trauma` `heal` `heal_psyche` `bond` `hire` `leave_column` `dismiss` `death` `level` `buy` `crime`

Примеры строк: «получила травму рука», «встала за стол», «получила уровень 3».

### Дефолт сейва без `id` — в коде сейчас

`migrate_legacy_status`: `(ключ, царапина|рана)` → существующий `STATUSES`. `увечье` читается как серьёзная (не крит). Перманент сохраняется флагом, отдельного id нет.

Спека хотела: рука увечье → `arm_break`, perm → `arm_lost`. Этого маппинга нет.

### Что не плодить

Не делать шаблон «получи статус X» на каждый id. Новые грани, если собирать — машиной узла, журнал сухой: «получила травму рассудка: паника».

Mundane-такты (`wet_step`, `lamp_hiss`, …) не статусы и не резать.
