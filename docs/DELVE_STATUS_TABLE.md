# Таблица статусов колонны (плоть + рассудок)

Слой поверх `CompanionCard.flesh[]` / `psyche[]` и PQ-HP.  
Канон карточки и летописи не ломаем: те же 5 частей тела, те же 4 старых граней, лесенка `царапина < рана < увечье`, потолок 3+3.  
Меняется смысл: статус больше не только память журнала. Он режет `party_power`, растягивает такт узла, множит веса летописи и сток.

Связанные документы: [DELVE_PROGRESS_QUEST_TZ.md](DELVE_PROGRESS_QUEST_TZ.md), [TAVERN_LIVING_COMPANIONS.md](TAVERN_LIVING_COMPANIONS.md), [DELVE_ROLEPLAY.md](DELVE_ROLEPLAY.md).  
Каталог тактов: `data/delve_events.v1.json`.

---

## 0. Совместимость слота

Старый слот жив. Новый id пишется рядом.

```
flesh[]   = {id, part, severity, permanent, returns_left?}
psyche[]  = {id, facet, severity, permanent, returns_left?}
```

| Поле | Канон | Новое имя на HUD |
|------|--------|------------------|
| `part` | `рука` `нога` `лицо` `глаз` `рёбра` | без изменений |
| `facet` | `страх` `ярость` `вина` `боится_тьмы` + 4 новых | см. §3 |
| `severity` | `царапина` / `рана` / `увечье` | лёгкая / серьёзная / критическая |
| `permanent: true` | уже есть | перманентная (четвёртая ступень) |
| `id` | нет в старых сейвах | ключ строки этой таблицы |
| `returns_left` | нет | сколько городских возвратов осталось |

Старый ряд без `id`: `{part, severity, permanent}` читается как дефолт части/грани той же ступени (таблица §8).  
`scar_frame` ставится на серьёзную+ плоть и **не** снимается с лечением.  
`silhouette_dirty` — только `рука` `нога` `лицо` `глаз` (как сейчас). `рёбра` силуэт не пачкают.

Маппинг ступеней:

| HUD | `severity` | `permanent` |
|-----|------------|-------------|
| лёгкая | `царапина` | false |
| серьёзная | `рана` | false |
| критическая | `увечье` | false |
| перманентная | `увечье` | true |

## 1. Законы (8)

| # | Закон |
|---|--------|
| **S1** | Два вреда. PQ HP — ресурс спуска. Flesh/psyche — память карты. Wipe, зелье и мазь наполняют HP. Статусы с этого не снимаются. |
| **S2** | Цель — лицо, цена — колонна. Статус висит на одной карте. `% силы` бьёт `power` этой карты. Tick и drain складываются по отряду. Веса летописи — на стол, в строке журнала есть имя. |
| **S3** | Один ключ — один слот. Ключ плоти = `part` (5). Ключ рассудка = `facet`. Повтор по ключу не плодит второй слот: эскалация вверх, слабый удар игнор. |
| **S4** | Потолок 3 плоти + 3 рассудка на карту. Партийного капа нет. Замена — §5. |
| **S5** | Лесенка = сила + срок. Лёгкая сгорает в ближайшем лагере (REST **или** SURFACE, что раньше). Серьёзная живёт N городских возвратов. Критическая — N возвратов и **только** SURFACE/wipe, не REST. Перманентная — никогда. |
| **S6** | Кран игрока свят. Статусы не трогают `Player.gold` и XP ОВ. Режут `effective_power` → `party_power` → `d_max`, сток, интервал узла, веса летописи, шанс `leave_column` / `death`. |
| **S7** | Честный чип. HUD: короткое имя + срок. В карточке — одно предложение. Не «тень легла». |
| **S8** | Один бросок на тип на узел. COMBAT / BOSS / TRAVERSE: не больше 1 плоти и 1 рассудка на **весь** отряд (не ×3 головы). Потом выбор цели. Новая карта и новый зал — grace §7. |

Формулы, которые статусы имеют право трогать:

```
effective_power(card) = max(1, round(card.power * (1 + Σ power_pct)))
party_power'          = Σ effective_power(живых)
d_max'                = floor(8 + 0.35 * party_power')

T_node                = 30 * tick_mult          # сек на узел спуска; кран игрока не здесь
tick_mult             = clamp(1 + Σ tick_pct, 0.82, 1.40)     # >1 = медленнее

drain'                = max(min_drain, round(drain * clamp(1 + Σ drain_pct, 0.75, 1.55)))
REST_regen(card)      = 0.10 * hp_max * clamp(1 + regen_pct, 0.40, 1.00)

вес_шаблона'          = clamp(вес * Π event_mult, 0.25, 3.50)
```

`tick_pct > 0` = колонна ползёт (узел длится дольше). `tick_pct < 0` = быстрее, обычно ярость/одержимость.  
Каналы весов летописи: `w_leave` `w_injury` `w_trauma` `w_heal` `w_bond+` `w_bond−` `w_death` `w_shop` `w_rest` `w_boss`.

Клампы на одну карту: `Σ power_pct ∈ [−0.50, +0.15]`. На отряд: tick и drain — как выше.

## 2. Модель срока: что такое «лагерь»

Два разных костра. Путать нельзя.

| Имя | Что это в коде | Как часто при 30 с/узел | Что лечит |
|-----|----------------|-------------------------|-----------|
| **REST-лагерь** | узел `REST` (`d % 8 == 6`), костёр **на спуске** | ~каждый 8-й узел ≈ **4 мин** | все **лёгкие** на всех картах; HP +10% как в TZ; 30% у целительницы снять 1 возврат с одной серьёзной |
| **SURFACE / город** | узел `SURFACE` (пила на `d=0`, фаза `T_rest`) **или** PQ-wipe | пила ≈ **25–45 мин**; wipe у новичка ≈ **50–70 мин** | лёгкие, если дожили; **серьёзные и критические** тикают `returns_left − 1` |

**Городской возврат** (`city_return`) — это SURFACE **или** wipe. Оба. Счётчик один.

Wipe делает ровно это, в этом порядке:

1. Все живые: `hp_current = hp_max`.
2. `wipe_count += 1`, `city_return += 1`.
3. Лёгкие снять.
4. У серьёзных и критических `returns_left − 1`; при 0 — снять (если не `permanent`).
5. Экип, сумка, уровень, кошельки, перманентные, оставшиеся статусы — как были.
6. Спуск после `T_rest`.

Не город и не лагерь:

| Узел | Статусы |
|------|---------|
| COMBAT / BOSS / TRAVERSE | могут **выдать** статус (S8) |
| SHOP / BRANCH / LANDMARK | не выдают плоть/рассудок; не лечат |
| Зелье / мазь | только PQ HP |
| Исход `heal` / `heal_psyche` | редкая строка стола: −1 ступень или −1 возврат (не перманент) |

Целительница в отряде (живая, сама не в критической плоти): на каждом REST 30% выбрать одну серьёзную в отряде (сначала свою, иначе самую тяжёлую) и сделать `returns_left − 1`. На SURFACE — 100% один такой тик, если есть серьёзная. Критическую и перманентную не трогает.

## 3. Сколько висит и как заменяем

На карту: **≤3 flesh + ≤3 psyche**. На отряд из 3: теоретический потолок 18. Бюджет §7 не даёт к этому прийти за сессию.

Ключ = `part` или `facet`. Алгоритм прихода нового статуса `N` на карту `C`:

1. Есть слот с тем же ключом:
   - ступень `N` > текущей → заменить, перезаписать `id`, `returns_left`, `permanent`;
   - ступень `N` = текущей и не перманент → **40%** эскалация на +1 ступень (рана→увечье, увечье→перманент **запрещён** этим путём: потолок эскалации = критическая);
   - ступень `N` < текущей → игнор.
2. Ключа нет, слотов < 3 → дописать.
3. Ключа нет, слотов = 3:
   - `N` лёгкая → игнор (царапина не вышибает рану);
   - `N` серьёзная+ → выгнать самый слабый **неперманентный** (при равенстве — самый старый);
   - все три перманент → игнор.
4. Перманент никогда не выгоняется неперманентом.
5. Смерть / `leave_column` снимают карту из колонны. Статусы уходят с ней в архив (для таверны / поминовения), на отряд больше не действуют.

Эскалация 40% — это тот же ключ, не новый слот. Игрок видит смену чипа: «Порез руки» → «Сломанная рука».

Выбор цели после удачного броска узла:

```
вес(карты) = 1.00
  × стойка: scout на TRAVERSE ×1.45, на COMBAT/BOSS ×0.85
            shield на COMBAT/BOSS ×1.45, на TRAVERSE ×0.80
            guide на любом ×0.90 к плоти, ×1.20 к рассудку
  × класс и черты строки (колонка «моды», перемножить)
  × 0.80 если у карты уже 3 слота этого семейства
  × 1.20 если ключ этой строки у карты пуст (размазать по отряду)
```

Последнюю живую AFK **не** убиваем (L-last). Статус на неё вешать можно.

Черта `боится_тьмы` — врождённая, слот не ест. Статус `боится_тьмы` — отдельный слот. Если есть оба, множители `w_leave` перемножаются.

## 7. Бюджет шансов (3 головы, 30 с/узел)

Смесь узлов на длинной дистанции (хребет 2.2 + пила): COMBAT **32%**, BOSS **10%**, TRAVERSE **22%**, прочие **36%**.  
Час = 120 узлов → 38.4 COMBAT, 12 BOSS, 26.4 TRAVERSE.

Ожидаемые **проки** (до grace, до модов, отряд целиком):

| | Плоть | Рассудок | Всего |
|--|------:|---------:|------:|
| Проков / час | 7.94 | 3.66 | **11.6** |
| из них лёгких | 5.52 | 2.34 | 7.86 |
| серьёзных | 1.94 | 0.95 | 2.89 |
| крит | 0.44 | 0.31 | 0.75 |
| перм | 0.07 | 0.06 | 0.13 |

Срок → сколько **висит одновременно** в равновесии (без grace):

| Ступень | Срок | Висит на отряде |
|---------|------|-----------------|
| лёгкая | ~2 мин до ближайшего REST (сред. ожидание 2 мин, макс 4) | **~0.3** |
| серьёзная | 1–2 города ≈ 25–50 мин | **~1.4** |
| крит | 2–3 города ≈ 50–90 мин | **~0.7** |
| перм | навсегда | **+0.13 / час** игры ≈ 1 на карту за ~8 ч колонны |

Итого типичная сессия 40–60 мин: **1–2 серьёзных чипа на отряд, иногда один крит, лёгкие мелькают и сгорают у костра.** Это чувствуется (сила −8…−18% на одной голове = −3…−6% `party_power`, сток +10…+20%, такт +8…+16%). Это не кирпич.

### Первые 10 минут (нельзя сломать новичка)

**Grace S8.** Пока верно хоть одно:

- карта сидит < 15 узлов с `joined_at`;
- у зала `wipe_count = 0` и в колонне < 20 узлов с первого sync;

множители броска: серьёзная ×0.35, крит ×0.15, перм ×**0**. Лёгкая без штрафа.

20 узлов (10 мин) почти целиком в grace:

| | Ожидание за 10 мин |
|--|-------------------:|
| лёгкая | 1.3 |
| серьёзная | 0.17 |
| крит | 0.02 |
| перм | 0.00 |

P(хотя бы одна серьёзная за 10 мин) ≈ **16%**. P(крит) ≈ 2%.  
Лёгкая сгорит на первом REST (узел 6 ≈ 3-я минута). Новичок видит чип «Синяк · до костра», не «Нет руки».

После grace сессия 50 мин: ~2.4 серьёзных прока, ~0.6 крит, перм ≈ 8%. Норма.

### Потолок «плохого дня»

Даже без удачи клампы не дают нулевой силы и нулевого движения. Три крита на трёх головах: tick_mult кламп 1.40 (узел 42 с вместо 30), drain ×1.55, `party_power` примерно −15…−25%. Спуск тяжелее и короче по `d_max`, кран игрока тот же. Карту из колонны вышибает только `leave_column` / `death` — редкие шаблоны, которые статусы множат, но не гарантируют.

## 9. Что делать со старыми шаблонами летописи

Исход `injury` больше не пишет голую `{part, severity: "рана"}`. Шаблон несёт `status_id`. Если id нет — дефолт части на ступени «серьёзная».  
Исход `trauma` — то же с `status_id` / `facet`.

Веса шаблонов — те же числа, что в `delve_events.v1.json`. Статусы множат их через каналы §1, не через правку JSON вслепую.

| `need_wound` | `bool(flesh or psyche)` | как строка выше |
| L-heal («лагерь не лечит») | закон таверны | **снять для лёгких**. Серьёзные по-прежнему не лечит REST, кроме 30% целительницы |
| L-weather («пила не знает ран») | закон | **снять**. Чипы на рамке. Строка «Спуск · тяжело» может остаться погодой пилы; tick_mult — отдельный слой |
| L-digest | увечье / срыв в грифеле | чип `критическая` / `перманентная` = тяжёлый бит; лёгкая в грифель не лезет |

### Дефолт для сейвов без `id`

| Старый слот | Читать как |
|-------------|------------|
| рука царапина | `arm_graze` |
| рука рана | `arm_cut` |
| рука увечье | `arm_break` |
| рука увечье + permanent | `arm_lost` |
| нога царапина / рана / увечье / perm | `leg_twist` / `leg_wound` / `leg_break` / `leg_lame` |
| лицо | `face_bruise` / `face_cut` / `face_ruin` / `face_mark` |
| глаз | `eye_soot` / `eye_hurt` / `eye_blind` / `eye_gone` |
| рёбра | `rib_bruise` / `rib_crack` / `rib_break` / `rib_cage` |
| страх | `fear_tremor` / `fear_wound` / `fear_horror` / `fear_broken` |
| ярость | `rage_spark` / `rage_wound` / `rage_frenzy` / `rage_eternal` |
| вина | `guilt_prick` / `guilt_wound` / `guilt_eat` / `guilt_brand` |
| боится_тьмы | `dark_ask` / `dark_wound` / `dark_never` / `dark_forever` |

`returns_left` при миграции: лёгкая — пусто; серьёзная — 1 (глаз и тьма — 2); крит — 2 (лицо, вина, тьма, одержимость — 3); перм — пусто.

### Не плодить

Не добавлять шаблоны «получи статус X» на каждый id. Пять плоти + четыре старых травмы + быт — достаточно. Новые грани (`паника` и т.д.) приходят **машиной узла** §4, не новой прозой. Журнал пишет одну фактическую строку:

`{who} получает «Паника · 1 город».`

Этого хватает. LLM-spice (18% особых) может переписать уже решённое, не выбирая id.

### Убрать из канона (ретайр смысла, не обязательно строки JSON)

| Вещь | Почему |
|------|--------|
| «Раны кусают только завтрашнюю летопись, не силу» (роль 2.2 / таверна) | Прямо отменено этим ТЗ. Летопись остаётся, плюс сила/такт/сток. |
| Автолечение только редкой строкой стола | Лёгкая лечится лагерем. Строка стола — для серьёзной ступени. |
| HP-бар на стволе из-за плоти | По-прежнему нет. HP — PQ. Чип статуса — не бар. |
| Кнопка «лечить» в модалке | Нет. Город и костёр — авто. |
| Исход `injury`/`trauma` без ступени | Ретайр ветки в `apply_outcome`. |

Mundane-шаблоны (`wet_step`, `lamp_hiss`, `share_bread`, …) **не** ретайрим: они держат стол живым, когда статусов нет.

## 10. Сводка для сборки

1. Слот карты не менять. Добавить `id` + `returns_left`.
2. На COMBAT/BOSS/TRAVERSE бросать плоть и ум по §4, один раз на отряд.
3. REST снимает лёгкие. SURFACE и wipe тикают город.
4. `effective_power` вместо голого `power` в `party_power`, drain, `d_max`.
5. `T_node = 30 * tick_mult` только для колонны, не для крана игрока.
6. HUD: чип + одно предложение из §8.
7. Grace на первые 15–20 узлов.
8. Пять старых injury-шаблонов и четыре trauma привязать к id; `eye_soot` и `leg_twist` понизить до лёгких; L-heal и L-weather снять.

Это чувствуется за сессию и не ломает первый костёр.
