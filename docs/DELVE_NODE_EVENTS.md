# ТЗ: события рядового узла (слой PQ)

Статус: к реализации. Не код — контракт театра.

Связано: [DELVE_PROGRESS_QUEST_TZ.md](DELVE_PROGRESS_QUEST_TZ.md), `data/delve_events.v1.json`, `PHRASES` в `delve_catalog.py`, карточка вала в `delve.js`.

## Законы

| # | Закон |
|---|--------|
| **E1** | Рядовой узел = один резолв из каталога. Игрок не кликает. |
| **E2** | Сначала механика (HP / золото кошелька / статус / ничего), потом строка. LLM только переписывает середину уже посчитанной строки. |
| **E3** | Сид: `sha256("pq-kind:{pq_seed}:{cycle}:{d}")` → вид; `sha256("pq-row:{pq_seed}:{cycle}:{d}:{kind}")` → строка каталога; `sha256("pq-who:{…}")` → кто из живых. Один вход → один кадр. |
| **E4** | Монстр ≠ второй бой. Тот же `combat_drain(d, party_power)`, множитель `hp_mult` из строки. Имя в тексте. |
| **E5** | Золото узла — в `gold_wallet` наёмницы, не в `Player.gold`. Остаток дневного капа PQ. Кап полон → дельта 0, в суффиксе «кап дня». |
| **E6** | Особые узлы не берут этот каталог: `SHOP` / `BRANCH` / `REST` / `LANDMARK` / `BOSS` / `SURFACE`. Их текст свой. `shop_log` и штампы журнала не трогать. |
| **E7** | Резолв только на спуске. Подъём те же `d` не крутит события повторно. |
| **E8** | Строка карточки всегда: кто / что / итог. Запрещено `{имя}: {имя} …`. |

## Что ломается сейчас

`spine_type`: особые по формуле, иначе `TRAVERSE` если `d < 0.35 * ceil`, иначе `COMBAT`. При `d_max ≈ 8` рядовых узлов мало (1, 2, 3, 8, 9), и «бой» значит только сток без имени.

Карточка: `PHRASES` (`{name} идёт дальше`) + опционально LLM 8–20 слов. Летопись: 40 литературных шаблонов (`{who} слышит своё имя — и не оборачивается`). Итог: «Милфа: Милфа слышит своё имя…» — нет предмета, нет числа.

## 1. Виды рядового узла

`TRAVERSE` и `COMBAT` как типы хребта **снимаются**. После фильтра особых формула больше не смотрит на 35% потолка.

Класс у наёмницы нет. «Класс» = стойка: `scout` / `shield` / `guide`. Нрав: `curiosity` / `temper` / `stay`.

| id | Метка | Глиф | Сток | Золото кошелька | Статус | Комментарий |
|----|-------|------|------|-----------------|--------|-------------|
| `empty` | Ничего | · | нет | нет | нет | Тишина — валидный исход, не дыра в каталоге |
| `monster` | Монстр | ✕ | `combat_drain × hp_mult`, делёж по живым как сейчас | нет (кран отдельно) | бросок из строки, редко | Именованная встреча, не движок боя |
| `event` | Событие | ! | `0` или `combat_drain × hp_mult` (обычно 0.35–0.60) | `gold_delta` если задан | бросок из строки | Среда / оступ / удача. Не монстр |
| `npc` | NPC | ◊ | нет (исключение: пошлина 0 HP) | `gold_delta` (+ подарок / − пошлина) | бросок из строки | Человек, не лавка. Лавка = `SHOP` |
| `find` | Находка | ◇ | нет | `gold_delta` > 0 | нет | Отдельно от `event`: видно «нашла монеты», не «что-то случилось» |

Пятый вид `find` нужен: иначе золото на узле прячется внутри «события», и игрок не отличает щель с монетами от обвала.

Веса ниже — доли **среди рядовых** узлов (особые уже вычтены). Банда `ceil(d / 20)`, как в PQ.

| kind | d 1–8 (банда 1, старт) | банда 1 (1–20) | банда 2 (21–40) | банда 3+ (41+) |
|------|----------------------:|---------------:|----------------:|---------------:|
| `empty` | 42 | 28 | 14 | 10 |
| `monster` | 22 | 36 | 50 | 56 |
| `event` | 18 | 20 | 22 | 22 |
| `npc` | 12 | 10 | 8 | 6 |
| `find` | 6 | 6 | 6 | 6 |
| **сумма** | 100 | 100 | 100 | 100 |

Внутри банды 1 старт (d≤8) жирнее `empty`, чтобы первые часы читались как «шли и иногда кусали», не как коридор боёв.

Предпочтение актора (не смещает вид, только кто в строке):

| kind | prefer_stance | prefer_temper |
|------|---------------|---------------|
| `empty` | guide | stay |
| `monster` | shield (цель удара) | stay |
| `event` | scout | curiosity / temper |
| `npc` | guide | curiosity |
| `find` | scout | curiosity |

Нет подходящей — первый живой по слоту, сдвиг по сиду.

Статусы v1 (закрытый список, висят на карточке, сбрасываются на wipe):

| id | Метка | Длит. (узлы) | Эффект |
|----|-------|-------------:|--------|
| `bleed` | кровотечение | 2 | следующая встреча `monster`/`event` со стоком: +1 HP этой карточке |
| `poison` | яд | 2 | каждый следующий рядовой: −1 HP этой карточке |
| `ward` | оберег | 1 (до первого монстра) | следующий `monster`: `hp_mult × 0.75` |
| `limp` | хромота | до `REST` | этот костёр: реген × 0.5 |

Нет брони, нет уклонения, нет ответного урона.

## 2. Смесь на контрольных глубинах

Доли вида, если узел рядовой. Особые на этой глубине вид не крутят.

| kind | d=1–8 | d=20 | d=40 |
|------|------:|-----:|-----:|
| Ничего | 42% | 28% | 14% |
| Монстр | 22% | 36% | 50% |
| Событие | 18% | 20% | 22% |
| NPC | 12% | 10% | 8% |
| Находка | 6% | 6% | 6% |

На старте `d_max ≈ 8` рядовые обычно: **1, 2, 3, 8, 9**. Остальное — лавка 4, вилка 5, костёр 6, метка 7, босс 10. Смесь 1–8 бьёт в эти 4–5 кадров.

`d=20` и `d=40` сами боссы — таблица для **соседних рядовых** той же банды (17–19 / 37–39 и т.п.), чтобы художник вала знал глифы главы.

Интерполяция внутри банды не нужна: дискретная таблица банды. Граница 20/21 — скачок весов, не плавный lerp (проще сид и тесты).

Ориентир стока, `party_power ≈ d` (вровень):

| Узел | Формула | Пример d=8, power=8 | d=20, p=20 | d=40, p=40 |
|------|---------|---------------------:|-----------:|-----------:|
| `monster` hp_mult 1.0 | `max(1, round(4+0.45×gap))` | −4 | −4 | −4 |
| `monster` hp_mult 1.4 | то же ×1.4 | −6 | −6 | −6 |
| `event` hp_mult 0.5 | то же ×0.5, min 0 если в строке 0 | −2 | −2 | −2 |
| `empty` / `find` / `npc` | 0 | 0 | 0 | 0 |
| `BOSS` (не этот каталог) | `boss_drain` | — | −10 | −10 |

Если `d > party_power`, gap растёт как в PQ. Имена меняются, формула нет.

## 3. Схема каталога

Новый файл: `data/delve_node_events.v1.json`. Летопись `delve_events.v1.json` сюда не смешивать.

```json
{
  "version": 1,
  "kinds": ["empty", "monster", "event", "npc", "find"],
  "templates": [ { "…строка…" } ]
}
```

Поля строки:

| поле | тип | обязат. | смысл |
|------|-----|---------|--------|
| `id` | string | да | стабильный ключ, латиница |
| `kind` | enum | да | один из пяти |
| `title_ru` | string | да | короткое имя кадра («Крысолюд», «Монета в щели») |
| `line_ru` | string | да | факт. Плейсхолдеры: `{actor}`, `{who}`, `{other}`. Без итога в скобках — суффикс собирает движок |
| `actor` | string \| null | да | кто действует: имя монстра / NPC / `null` у empty/find/части event |
| `result_tags` | string[] | да | подмножество: `hp`, `gold`, `status`, `none` |
| `status_roll` | object \| null | да | `{ "id", "chance", "duration", "label_ru" }` или `null` |
| `hp_mult` | number | да | 0 = стока нет. Иначе множитель к `combat_drain` |
| `gold_delta` | int | да | в кошелёк выбранной `{who}`, может быть < 0 |
| `when` | object | да | фильтр eligibility |
| `prefer_stance` | string \| null | нет | `scout` / `shield` / `guide` |
| `prefer_temper` | string \| null | нет | `curiosity` / `temper` / `stay` |
| `prefer_trait` | string \| null | нет | тег `adventure_tags` / `traits` («жадная», «боится_тьмы»). Нет тега — строка всё равно жива, вес без бонуса |
| `weight` | number | да | вес внутри kind после фильтра `when` |

`when`:

| поле | тип | default | смысл |
|------|-----|---------|--------|
| `d_min` | int | 1 | |
| `d_max` | int \| null | null | null = без потолка |
| `biomes` | string[] \| null | null | id шахты (`wet`, `mushrooms`, …). null = любой |
| `hp_pct_max` | number \| null | null | только если у выбранной hp% ≤ порога |
| `need_gold` | bool | false | `gold_delta` < 0: должна быть монета в кошельке, иначе строка выпадает из пула |

Отбор: `kind` уже выбран весами банды → пул строк этого `kind` с прошедшим `when` → вес × 1.25 если `prefer_*` совпал с кем-то живым → бросок. Пул пуст → фолбэк `empty.quiet_shaft`.

`line_ru` — сухой факт, 6–14 слов. Запрещено: эхо, «не оборачивается», «не спрашивает», «тишина чужая».

## 5. Сборка строки карточки

Три куска. Склейка пробелами. Точка только внутри `line`.

```
[{kind_ru}] Глубина {d} · {line} {result}
```

`result` — скобки, только факты после резолва:

| условие | суффикс |
|---------|---------|
| только HP | `(−6 HP)` |
| HP по двум лицам | `(Милфа −4 HP, Сера −2 HP)` — если делёж, в середине имя цели, в скобках сумма отряда **или** разбивка, если живых ≤ 3 |
| только золото + | `(+3 зол.)` |
| только золото − | `(−2 зол.)` |
| золото 0 из-за капа | `(кап дня)` |
| HP + золото | `(−2 HP, +4 зол.)` |
| статус прокнул | после скобок: ` · кровотечение` |
| `none` и empty | без скобок |
| зелье после стока | не в этой строке (автоюз уже есть; не плодить второй лог) |

Примеры живых кадров:

- `[Монстр] Глубина 12 · Крысолюд ударил Милфу (−6 HP)`
- `[Монстр] Глубина 12 · Крысолюд ударил Милфу (−6 HP) · кровотечение`
- `[Ничего] Глубина 3 · Ход пуст. Милфа прошла без встречи`
- `[Событие] Глубина 7 · Милфа оступилась на мокрой ступени (−2 HP)`
- `[NPC] Глубина 16 · Старьёвщик отдал Милфе мелочь и ушёл вверх (+3 зол.)`
- `[Находка] Глубина 5 · Сера вытащила монеты из щели в стене (+3 зол.)`

Кикер над строкой остаётся биомом: `Спуск · мокрый камень`. Вид живёт в `[скобках]`, не в кикере.

Запрещено:

- `{who}: {line}`
- LLM-строка без `[вида]` и без суффикса
- подставлять имя в начало, если его нет в `line` (`enforcePhraseNames` так ломает кадр)

LLM (открытая вкладка, после резолва):

1. Есть готовые `kind_ru`, `d`, `line`, `result`.
2. Модель может заменить только `line` (8–20 слов, те же `{actor}`/`{who}`, те же факты).
3. Числа, вид, глубину не выдумывать.
4. Провал / таймаут → каталожная `line_ru`.

Особые узлы — не каталог, свои формулы:

| node | строка |
|------|--------|
| `SHOP` | как сейчас: `Милфа купила Клинок T1` из `shop_log` (−3 последних) |
| `REST` | `[Костёр] Глубина 14 · Милфа села у угля (+5 HP)` (факт `REST_REGEN`, с учётом `limp`) |
| `BRANCH` | вилка 15 с как сейчас; если хром скрыт: карточка пустая. Не подменять `TRAVERSE`-фразой |
| `LANDMARK` | `[Метка] Глубина 13 · Милфа отметила камень` |
| `BOSS` | `[Босс] Глубина 10 · Хозяин яруса ударил отряд (−12 HP)` — один титул на банду, тот же `boss_drain` |
| `SURFACE` | `[Лагерь] Отряд наверху` |

## 6. Старые PHRASES и 40 шаблонов летописи

| источник | роль сейчас | решение |
|----------|-------------|---------|
| `PHRASES.TRAVERSE` / `COMBAT` | фолбэк карточки | **Снять.** Не кормят вал |
| `PHRASES.REST/SHOP/BRANCH/LANDMARK/BOSS/SURFACE` | фолбэк особых | **Переписать** в формулы §5. Пулы `{name} кивает лавке` удалить — лавка уже `shop_log` |
| `PALETTE_FLAVOR` | вторая поэтическая фраза | **Не на карточку.** Биом = арт + кикер |
| `phrase_for()` | сид + пул PHRASES | Заменить сборщиком каталога. Функцию оставить мёртвой до выпила тестов |
| `data/delve_events.v1.json` (40) | такт летописи 2 ч, раны / нрав / уход | **Не на карточку вала.** Файл жив для `CompanionEvent` |
| шаблоны `when: TRAVERSE/COMBAT` в 40 | биты «шла / держала строй» | **Переименовать `when` → `regular`** или оставить мёртвыми: хребет больше не шлёт TRAVERSE/COMBAT |
| `echo_name`, `abyss_quiet`, `joke_dark` | загадка | Не переносить в новый каталог без переписывания в факт |
| `wet_step` / `leg_twist` летописи | почти факт, но без HP | Смысл перенесён в новые `wet_step` / монстров. Старые id не переиспользовать |
| outcomes `injury` / `trauma` / `leave` / `death` / `bond` | плоть, уход, шрам | Остаются **только** на такте летописи. Рядовой узел не калечит и не увольняет — иначе каждый шаг = драма |
| pin `CATALOG_SHA256_PREFIX` | страж 40 шаблонов | Не трогать, пока не меняют `delve_events.v1.json` |

Два слоя текста:

| слой | частота | сила | куда |
|------|---------|------|------|
| Каталог узла (этот документ) | каждый рядовой `d` на спуске | HP / золото кошелька / 4 статуса | карточка вала, `GET /delve/sync` |
| Летопись 40 | ~2 ч | плоть, психика, связь, уход | таверна / `CompanionEvent`, не карточка |

`GET /delve/sync` без LLM. Строка уже собрана.

`band_nodes[]` сейчас `{d, type}`. Станет:

| поле | рядовой | особый |
|------|---------|--------|
| `d` | 12 | 10 |
| `type` | `monster` (не `COMBAT`) | `BOSS` |

Клиент **не** считает вид из `d < 0.35 * ceil`. Без `band_nodes[].kind` трек врёт после смены весов.

`frame.phrase` = `event.phrase`. Старый фолбэк `phrase_for` не звать.

`POST /delve/line`: не заменяет `phrase` целиком. Ответ:

```
{ "phrase": "<полная сборка>", "line_ru": "<только середина>", "from_llm": true, "event_id": "ratfolk_hit" }
```

Кэш ключ: `{pq_seed}:{cycle}:{d}:{event.id}:{who}`, не `{d}:{TRAVERSE}:{palette}`.

На клиенте выкинуть префикс имени, если `line` уже содержит имя. Пока открыта вкладка и `d` тикает локально: брать `phrase` из `recent_events`/`event_by_d` текущего `d`; нет записи — оставить прошлую до следующего sync (не выдумывать TRAVERSE).

Опционально в sync: `event_by_d: { "12": {phrase, kind}, … }` на видимую банду. Прошлое — факт (цифры после PQ). Будущее — только `kind` + каталожная линия **без** цифр HP (сток ещё не был). Цифры дописывает sync, когда `d` достигнута. Иначе клиент покажет −6 до удара.

`journal` не получает чипы «Крысолюд на 12». Журнал = лавка / метка / срыв / wipe.

## Порядок резолва узла (авто)

Только спуск, `d` целое, узел не особый:

1. Вид по весам банды и сиду.
2. Пул строк вида, фильтр `when`, вес + prefer.
3. Выбрать `{who}` среди живых (prefer, иначе слот × сид).
4. Сток / золото / бросок статуса. Потом авто-зелья как сейчас.
5. Собрать `phrase`. Записать `recent_events` (хвост 3).
6. Wipe? Как PQ: штамп, HP max, статусы сброс, `cycle` сбрасывается с `run_origin` — следующие виды другие, это нормально.

Особый узел: шаг 1–5 каталога не бежать. SHOP/REST/BOSS — текущий PQ + строка §5.

## Приёмка

- На d=3 игрок читает «ход пуст» или «мыши оцарапали (−N HP)», не «не оборачивается».
- Два прогона с одним `pq_seed`, `cycle`, `d` → один `id`, одни дельты, одна `phrase`.
- `Player.gold` не меняется от `find` / NPC.
- Монстр не создаёт отдельный раунд, дроп, уклонение.
- Лавка по-прежнему пишет `shop_log`; штамп «Лавка на N» жив.
- Карточка никогда не формата `Милфа: Милфа …`.
- LLM выключен → на экране каталожная сборка.
- Глифы трека: · ✕ ! ◊ ◇ на рядовых; особые без изменений.
